# Sprint_6

Автотесты на Selenium для учебного сервиса [qa-scooter.education-services.ru](https://qa-scooter.education-services.ru/).

Проект собран как Maven-проект на Java 11 и покрывает обязательные сценарии: выпадающий список в блоке `Вопросы о важном` и позитивный сценарий заказа самоката с двумя точками входа.
